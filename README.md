# Placement Portfolio

A single repository showcasing two full-stack projects built with Java web technologies and the MERN stack.

## Projects

### 1. North India Tourism — Java Web Application
**Source repository:** [Tourism](https://github.com/Himanshu-tech9140/Tourism)

A tourism and travel-booking web application built with JSP/Java, JDBC, MySQL, and Apache Tomcat. The project includes destination pages, booking and enquiry workflows, and an administrative area. Razorpay integration is part of the project.

**Technology highlights:** Java · JSP · JDBC · MySQL · Apache Tomcat · HTML · CSS · JavaScript · Razorpay

[View original project](https://github.com/Himanshu-tech9140/Tourism)

### 2. NSS Exam Portal — MERN Full-Stack Application
**Source repository:** [NSS-Exam-portal](https://github.com/Himanshu-tech9140/NSS-Exam-portal)

An online examination portal with separate student and administrator workflows. The application includes authentication, exam participation, results, evaluation tools, and a leaderboard experience.

**Technology highlights:** MongoDB · Express.js · React · Node.js · Vite · REST APIs

[View original project](https://github.com/Himanshu-tech9140/NSS-Exam-portal)

## Getting Started

Each project has its own dependencies and setup requirements. Open the corresponding project directory and follow its README for project-specific instructions. Configure environment variables using the provided example files; never commit real credentials, API keys, or production secrets.

## Notes

- The original repositories remain the canonical sources for each project and their commit histories.
- This repository is intended as a combined showcase for placement applications.
- Database credentials, payment credentials, and other secrets should be supplied locally through environment variables.
